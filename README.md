# Dice Merge

Παζλ συγχώνευσης με ζάρια. Τρέχει σε browser και βγαίνει και σαν εφαρμογή Android.

## Τι υπάρχει εδώ

| Φάκελος / αρχείο | Τι είναι |
|---|---|
| `docs/index.html` | **Το παιχνίδι.** Όλος ο κώδικας σε ένα αρχείο. |
| `docs/manifest.webmanifest` | Ρυθμίσεις για «Προσθήκη στην αρχική οθόνη». |
| `docs/sw.js` | Κάνει το παιχνίδι διαθέσιμο χωρίς internet. |
| `docs/icon-*.png` | Εικονίδια για τον browser. |
| `resources/` | Εικονίδιο και splash σε μεγάλη ανάλυση, για το APK. |
| `capacitor.config.json` | Όνομα και ρυθμίσεις της εφαρμογής Android. |
| `android-workflow.yml` | Οι οδηγίες που χτίζουν το APK. **Δεν ανεβαίνει σαν αρχείο** — το περιεχόμενό του το επικολλάς στο GitHub (δες παρακάτω). |

## Πώς το παίζω στο κινητό (link)

Στο repo: **Settings → Pages → Source: Deploy from a branch → Branch: `main`, folder: `/docs` → Save**.

Μετά από ένα-δυο λεπτά το παιχνίδι είναι στο:

```
https://<ΤΟ-USERNAME-ΣΟΥ>.github.io/dice-merge/
```

Άνοιξέ το στο κινητό και κάνε «Προσθήκη στην αρχική οθόνη» για να παίζει σε πλήρη οθόνη, με εικονίδιο, και χωρίς internet.

## Πώς ενεργοποιώ το αυτόματο APK

Μία φορά, στο repo:

1. Καρτέλα **Actions** → **set up a workflow yourself**.
2. Σβήσε ό,τι έχει το πλαίσιο και επικόλλησε όλο το περιεχόμενο του `android-workflow.yml`.
3. Ονόμασε το αρχείο `android.yml` και πάτα **Commit changes**.

Το GitHub φτιάχνει μόνο του τον φάκελο `.github/workflows/` και ξεκινά αμέσως το πρώτο build.

## Πώς παίρνω το APK

Γίνεται μόνο του. Σε κάθε αλλαγή, η καρτέλα **Actions** χτίζει το APK (3–5 λεπτά) και το ανεβάζει στα **Releases**, στην έκδοση `latest`.

Από το κινητό: άνοιξε τα Releases, κατέβασε το `dice-merge.apk`, πάτα το. Την πρώτη φορά το Android θα ζητήσει άδεια για εγκατάσταση από άγνωστη πηγή.

Χειροκίνητο χτίσιμο: **Actions → Build APK → Run workflow**.

## Σημειώσεις

- Το APK είναι υπογεγραμμένο με debug key — μια χαρά για προσωπική χρήση, όχι για Play Store.
- Το πακέτο είναι `com.leonni.dicemerge` (αλλάζει στο `capacitor.config.json`).
- Δεν χρειάζεται να εγκαταστήσεις τίποτα στον υπολογιστή σου. Όλα χτίζονται στους servers του GitHub.
